## QueueEnumerator<T> - перечислитель для очереди

```csharp
public class QueueEnumerator<T> : IEnumerator<T>
```
- Объявляет класс `QueueEnumerator<T>`, который реализует интерфейс `IEnumerator<T>`
- `<T>` означает, что это обобщенный (generic) класс, который может работать с любым типом данных
- `IEnumerator<T>` - стандартный интерфейс C# для перебора элементов коллекции

```csharp
Queue<T> queue;
QueueItem<T> currentItem;
```
- `queue` - ссылка на очередь, которую будем перебирать
- `currentItem` - текущий элемент, на котором находится перечислитель

```csharp
public QueueEnumerator(Queue<T> queue)
{
    this.queue = queue;
    this.currentItem = null;
}
```
- Конструктор, принимает очередь для перебора
- `this.queue = queue` - сохраняет ссылку на очередь
- `currentItem = null` - в начале перечислитель не указывает ни на какой элемент

```csharp
public T Current
{
    get { return currentItem.Value; }
}
```
- Свойство возвращает значение текущего элемента
- Вызывается только после успешного MoveNext()

```csharp
public bool MoveNext()
{
    if (currentItem == null)
        currentItem = queue.Head;
    else
        currentItem = currentItem.Next;
    return currentItem != null;
}
```
- Перемещает перечислитель на следующий элемент
- Если `currentItem == null` (первый вызов) - переходит к голове очереди
- Иначе переходит к следующему элементу через `Next`
- Возвращает `true`, если удалось перейти (элемент существует)
- Возвращает `false`, если дошли до конца (currentItem стал null)

```csharp
public void Dispose() { }
object System.Collections.IEnumerator.Current
{
    get { return Current; }
}
public void Reset() { }
```
- `Dispose()` - освобождение ресурсов (пустой, так как нечего освобождать)
- `IEnumerator.Current` - необобщенная версия Current (для обратной совместимости)
- `Reset()` - сброс перечислителя (не реализован)

## Queue<T> - сама очередь

```csharp
public class Queue<T> : IEnumerable<T>
```
- Класс очереди, реализует интерфейс `IEnumerable<T>` (можно использовать в foreach)

```csharp
public virtual IEnumerator<T> GetEnumerator()
{
    throw new NotImplementedException();
}
```
- Должен возвращать перечислитель для очереди
- `virtual` - можно переопределить в наследниках
- Пока не реализован (выбросит исключение при вызове)

```csharp
System.Collections.IEnumerator System.Collections.IEnumerable.GetEnumerator()
{
    return GetEnumerator();
}
```
- Необобщенная версия GetEnumerator (требуется интерфейсом)
- Просто вызывает обобщенную версию

```csharp
public QueueItem<T> Head { get; private set; }
QueueItem<T> tail;
```
- `Head` - первый элемент очереди (публичное свойство, setter приватный)
- `tail` - последний элемент очереди (приватное поле)

```csharp
public bool IsEmpty { get { return Head == null; } }
```
- Свойство, проверяющее, пуста ли очередь

```csharp
public void Enqueue(T value)
{
    if (IsEmpty)
        tail = Head = new QueueItem<T> { Value = value, Next = null };
    else
    {
        var item = new QueueItem<T> { Value = value, Next = null };
        tail.Next = item;
        tail = item;
    }
}
```
- Добавляет элемент в конец очереди
- Если очередь пуста: новый элемент становится и головой, и хвостом
- Если не пуста: добавляем после хвоста и обновляем ссылку на хвост

```csharp
public T Dequeue()
{
    if (Head == null) throw new InvalidOperationException();
    var result = Head.Value;
    Head = Head.Next;
    if (Head == null)
        tail = null;
    return result;
}
```
- Удаляет и возвращает элемент из начала очереди
- Проверяет, что очередь не пуста
- Сохраняет значение головы, перемещает голову на следующий элемент
- Если очередь стала пустой, обнуляет tail
- Возвращает сохраненное значение

## QueueItem<T> - элемент очереди

```csharp
public class QueueItem<T>
{
    public T Value { get; set; }
    public QueueItem<T> Next { get; set; }
}
```
- Простой класс для элемента очереди
- `Value` - хранимое значение
- `Next` - ссылка на следующий элемент (null для последнего)

## Важные замечания

1. **Очередь работает по принципу FIFO** (First In, First Out) - первый пришел, первый ушел
2. **Перечислитель не меняет очередь**, только просматривает элементы
3. **GetEnumerator() не реализован** - чтобы использовать foreach, нужно его дописать
4. **QueueItem** образует односвязный список внутри очереди
